# miRNA.design.2025

This repository contains code for the design, analysis, and evaluation of a library of 3'UTRs and 5'UTRs containing miRNA target sites. [ADD LINK ONCE THE PAPER IS PUBLISHED]

## Contents

- General NGS analysis code to map NGS counts to UMIs per construct
- Design code for (Library 2) (e.g., the genetic algorithm)
- Analysis code for the ratiometric stability data (Library 2)
- Analysis code for Actinomycin D and Polysome Profiling (Library 3)
- Analysis code for the ratiometric stability data (Library 3)

## Usage

To generate the paper figures:

1. Generally, run the notebooks in order.
2. Some notebooks may need to be run multiple times or in a different order. This is indicated in the notebooks where necessary.
